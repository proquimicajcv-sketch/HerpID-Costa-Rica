# Checklist de recuperación y validación

## Arranque local
- [x] Verificar que la app se vea correctamente en el navegador
- [x] Confirmar que el puerto 3000 responda
- [x] Validar que el build de producción complete sin errores

## Configuración
- [x] Mantener Vite corriendo con host 0.0.0.0 y puerto 3000
- [x] Evitar configuraciones de base incompatibles
- [x] Dejar el punto de entrada de la app estable

## Validación rápida
- [ ] Abrir la app en el navegador
- [ ] Comprobar que no haya errores visibles en consola
- [ ] Confirmar que no aparezcan solicitudes fallidas
- [ ] Revisar que los cambios futuros no rompan el arranque
